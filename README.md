# 📖 PagePilot

**PagePilot** is a simple **online book borrowing system (client-side)** built using **HTML, CSS, and JavaScript**.  
It allows users to browse available books, borrow them online, and manage their borrowed list without needing a backend or server.  

---

## 🚀 Features
- 🔍 Browse and search available books  
- 📚 Borrow books with a single click  
- 📂 View and manage borrowed books  
- 🔄 Return borrowed books  

---

## 🛠️ Tech Stack
- **HTML** → Page structure  
- **CSS** → Styling and layout  
- **JavaScript** → Functionality (borrow, return, manage books)

## 💡 How It Works
1. Open `index.html` in your browser.  
2. Browse available books displayed on the page.  
3. Click **Borrow** to add a book to your borrowed list.  
4. Go to the **Borrowed Books** section to see your borrowed items.  
5. You can **Return** books anytime.
